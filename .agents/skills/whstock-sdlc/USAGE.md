# วิธีใช้งาน WH Stock Lean SDLC

## เริ่มใช้งาน

1. เปิดแชต Codex ใหม่ แล้วเลือกโปรเจกต์ `C:\code\whstocklocal` เพื่อให้ Codex โหลด Skill ประจำโปรเจกต์
2. พิมพ์ `$whstock-sdlc` แล้วตามด้วยงานที่ต้องการ
3. ระบุให้ชัดว่าต้องการให้เสนอแผนก่อนหรือให้ลงมือเลย และต้องการให้ทดสอบหรือไม่

## ตัวอย่างคำสั่ง

ตรวจและปรับหน้า UI:

```text
$whstock-sdlc ตรวจหน้า /desktop/stock-movements.html ว่า UI และข้อมูลเป็น LEAN หรือไม่ แล้วปรับจุดที่มีปัญหา
```

ให้พัฒนาและทดสอบ:

```text
$whstock-sdlc ปรับหน้ารายงานให้รอผู้ใช้กดค้นหาและแบ่งหน้าผลลัพธ์ Dev และ Test ด้วย
```

ขอแผนก่อน:

```text
$whstock-sdlc ตรวจ flow โอนข้ามคลังที่มีหลาย LOT รวมกรณีโอนบางส่วนและยกเลิก เสนอแผนก่อน ยังไม่ต้องแก้โค้ด
```

งานเล็กสามารถบอกผลลัพธ์ที่ต้องการสั้น ๆ ได้ Skill จะใช้ขั้นตอนตามความเสี่ยงของงาน ส่วนงานที่กระทบยอดสต๊อก หน่วย ANA/LOT สิทธิ์ หรือ schema ควรระบุกรณีที่ต้องคงพฤติกรรมและขอให้ตรวจสอบ/ทดสอบให้ชัดเจน

งานออกแบบหรือแก้หน่วยและอัตราบรรจุโดยตรง ใช้ `$whstock-packaging-units` ได้ หรือเรียก `$whstock-sdlc` ตามปกติ ซึ่งจะชี้ไปยังกติกาหน่วยบรรจุที่เกี่ยวข้องให้อัตโนมัติ

Skill หน่วยบรรจุเก็บไฟล์ `packaging-unit-converter.csv` ไว้เป็นอภิธานศัพท์อ้างอิง โดยแยกตัวอย่างออกจากอัตราจริงของสินค้าและกฎปฏิบัติการ

## การเปิดใช้งาน

Skill อยู่ที่ `.agents/skills/whstock-sdlc/` และใช้ได้กับแชตใหม่ที่เปิดโปรเจกต์นี้ หากเพิ่งสร้างหรือแก้ Skill ให้เริ่มแชตใหม่ก่อนเรียกใช้ `$whstock-sdlc`
