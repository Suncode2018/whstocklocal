# ส่งคลินิกและรายงานประจำวัน

ติดตั้งบน Dev LAPTOP-T4RLHQUE แล้ว: node scripts/migrate-product-clinic.js
SQL สำหรับติดตั้งด้วย SSMS: ProductClinicDelivery.sql (dbMaster, รันซ้ำได้)
สินค้าเดิมและใหม่เริ่มไม่อนุญาตส่งคลินิก ไม่เปลี่ยนยอดสต๊อก

## ส่งคลินิก
ข้อมูลสินค้า > แก้ไข > ข้อมูลสินค้า > ช่องทางการจ่ายสินค้า
Admin เปิด/ปิดและระบุหมายเหตุ กดบันทึกข้อมูลสินค้า
USER อ่านได้อย่างเดียว ค่าเดิมที่ไม่เปลี่ยนยังบันทึกข้อมูลส่วนอื่นได้
บันทึกการเปลี่ยนค่าใน ProductClinicAudit
หน้า Load ส่งคลินิกแสดงเฉพาะสินค้าที่เปิด และ API ตรวจซ้ำตอนสร้าง/เตรียม/ส่งจริง
Admin ไม่มีข้อยกเว้น ต้องเปิดสินค้าใน Master ก่อน
ใบส่งสำเร็จเดิมไม่ถูกแก้ไขเมื่อปิดสินค้า

## รายงาน
ศูนย์รายงาน > รายงานรับ–ส่งประจำวัน
/desktop/daily-operations.html
API /api/daily-operations?date=YYYY-MM-DD
ใช้ ReceivedAt / SentAt ตามเวลาเซิร์ฟเวอร์ เลือกวันที่เริ่มต้นตาม Bangkok
รับ PO เดิม / PO ใหม่ / ผลิต / รับโอนคลัง; ส่งลูกค้า / คลินิก / Fulfillment / คลัง / โรงงาน
ตัวกรองวัน งาน หมวด คลัง กลุ่ม และคำค้น
แสดงเฉพาะหมวด RECEIVE/LOAD VIEW และคลังที่มีสิทธิ์ ต้องเปิดเมนู REPORTS เพื่อเข้า
ยอดสรุปแยกทิศทาง หมวด และหน่วย ไม่รวมใบรับที่ยกเลิก
รายการรับที่ยกเลิกภายหลังแสดงสถานะปัจจุบัน ไม่ใช่รายงานยอดบัญชี ณ อดีต
รายงานนี้เป็นรายการรับ/ส่งจริง ไม่ใช่ dashboard งานรอหรือเทียบแผน
ต้องติดตั้ง WarehouseTransferWorkflow.sql ก่อนใช้รายงานรับโอนคลัง

หลังอัปเดตรีสตาร์ท npm start และ Ctrl+F5
ยังไม่ติดตั้งที่ DESKTOP-RT67GE0 และไม่ได้เปลี่ยนรายการสต๊อกจริง
