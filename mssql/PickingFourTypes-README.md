# การเบิก 4 กลุ่มสินค้า

ใช้ mssql/PickingFourTypes.sql กับฐานข้อมูล dbMaster และ dbWMS ก่อนรีสตาร์ทโปรแกรม

- RM: เต็มภาชนะ (จำนวนเต็ม) และแบ่งเบิก (ทศนิยม) แยกสิทธิ์ Desktop/HH
- PKG และ SEMI: หักยอดออกจากตำแหน่งจัดเก็บ
- FG: ย้ายไป OUT เพื่อรอจัดส่ง ยอดรวมคลังไม่เปลี่ยนจนยืนยันส่ง

Admin เลือก RM และตำแหน่งในหน้าเบิก แล้วกดตั้งค่าภาชนะ กำหนดหน่วยบรรจุ ปริมาณต่อภาชนะ หน่วยแบ่งเบิก และอัตราแปลงเป็นหน่วยสต๊อกจริงราย SKU ห้ามสมมติว่าลิตรเท่ากับ KG จากนั้นลงทะเบียนภาชนะเต็ม/เปิด แยกล็อตและวันหมดอายุ ยอดรวมต้องตรงกับยอดที่ยังไม่ลงทะเบียน การลงทะเบียนไม่เพิ่มสต๊อก

แบ่งเบิกใช้ภาชนะเปิดก่อนตามวันหมดอายุและลำดับรับ หากไม่พอ ต้องเลือกอนุญาตเปิดภาชนะใหม่ ไม่ใช้ภาชนะหมดอายุ และไม่เบิกเกินยอดหลังหักจอง

ฐานข้อมูลสต๊อกเดิมเก็บทศนิยม 2 ตำแหน่ง ระบบปฏิเสธรายการที่แปลงแล้วละเอียดเกิน 2 ตำแหน่ง เพื่อไม่ให้ปัดเศษยอดผิด

RM ที่มีภาชนะคงเหลือไม่อนุญาตปรับยอดรวม ตรวจนับปรับยอด หรือโอนออกแบบยอดรวม เพราะต้องรักษาความตรงกันของยอดภาชนะกับสต๊อก ระบบโอน/ปรับภาชนะแยกยังไม่ได้จัดทำ

สิทธิ์ USER เริ่มต้นไม่เปิด Admin ต้องกำหนด PICK_RM_WHOLE, PICK_RM_PARTIAL, PICK_PKG, PICK_SEMI, PICK_FG และการดู/ยืนยันตามงานที่รับผิดชอบ สิทธิ์ PICK เดิมยังใช้ได้จน Admin บันทึกเป็นสิทธิ์ย่อย
