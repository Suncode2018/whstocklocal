# ใบย้ายตำแหน่งภายในคลัง

ติดตั้ง Dev: `node scripts/migrate-location-moves.js` (จำกัด LAPTOP-T4RLHQUE)
ติดตั้งเครื่องอื่น: สำรอง dbWMS แล้วรัน LocationMoveOrders.sql ใน SSMS บนเครื่องเป้าหมาย จากนั้นอัปเดตโค้ดและรีสตาร์ท Service

หน้า /desktop/transfer.html: ลากสินค้าไปโลเคชั่น → ระบุจำนวนและเหตุผล → เลือกร่างหรือรอดำเนินการ → พิมพ์ใบงาน → ย้ายจริง → ยืนยันย้ายสำเร็จ
- ร่างไม่จองยอด ส่งใบงานจะตรวจสต๊อกและจองยอด
- รอดำเนินการจองต้นทาง ยังไม่ย้ายสต๊อก ยกเลิกได้และคืนยอดจอง
- สำเร็จตัดต้นทางและเพิ่มปลายทางใน SQL transaction เดียว พร้อมเลขเอกสารและผู้ยืนยัน กดยืนยันซ้ำไม่ตัดซ้ำ ยกเลิกไม่ได้
- หมายเลข MV-คลัง-วันที่-ลำดับ ใช้ identity ไม่รันใหม่รายวัน จึงไม่ซ้ำแม้มีหลายคนสร้างพร้อมกัน
- API สร้าง /api/stock-transfers/documents ใช้ EDIT ยืนยัน /documents/:id/complete ใช้ CONFIRM ตามสิทธิ์เมนู TRANSFER
- Trigger TR_Stock_LocationMoveReservation ป้องกันงานอื่นลดสต๊อกต่ำกว่ายอดจอง OPEN
- API เดิม POST /api/stock-transfers ยังย้ายทันทีสำหรับ client เดิม โดยตรวจยอดจองใบย้ายด้วย
- ANA/LOT บนใบงานเป็นข้อความที่ผู้ใช้ระบุ ไม่ใช่การจัดสรรล็อตจากบัญชีสต๊อกโดยอัตโนมัติ
- ไม่ตรวจความจุ และไม่รองรับข้ามคลังในใบงานชนิดนี้
- RM ที่ควบคุมภาชนะยังคงใช้ข้อกำหนดเดิม ห้ามย้ายยอดรวมโดยข้ามทะเบียนภาชนะ
- การติดตั้งไม่เปลี่ยนยอดสต๊อกเดิม
