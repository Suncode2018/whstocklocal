# รุ่นการจัดเรียงพาเลทใน Product Master

## ติดตั้ง

สำรอง dbMaster ก่อนเปลี่ยน schema ตั้ง DB_SERVER ใน .env ให้ตรงเครื่องที่จะอัปเกรด
สคริปต์ที่เรียกจาก Terminal ไม่ได้รับ environment ของ Windows Service
ต้องมี tblProductPackVersions และ migration ของระดับลังชั้นนอกก่อนใช้ OUTER

```powershell
cd C:\code\whstocklocal
node scripts/migrate-product-pallets.js
```

Migration รันซ้ำได้ สร้างเฉพาะ dbo.tblProductPalletVersions ใน dbMaster
ไม่แก้สินค้าเดิม รุ่นบรรจุเดิม tblStock หรือ dbWMS
หลังอัปเดตโค้ด รีสตาร์ท Node/Service และ Ctrl+F5 หน้าเว็บ

บน Laptop ใช้ `node createport/install.js restart --host LAPTOP-T4RLHQUE`
บน Desktop ใช้ `node createport/install.js restart --host DESKTOP-RT67GE0`

## ใช้งาน

Admin และ Desktop: ข้อมูลสินค้า > แก้ไข > การจัดเรียงพาเลท
สินค้าใหม่ต้องบันทึกสินค้าและมีรุ่นอัตราบรรจุก่อนเพิ่มรุ่นพาเลท

1. ระบุรหัสรูปแบบ เช่น STANDARD หรือ PALLET_100X120 และวันที่เริ่มใช้
2. เลือกรุ่นบรรจุ และหน่วยที่นำมาเรียง: PACK (กล่อง) หรือ OUTER (ลังชั้นนอก)
3. กรอกขนาดภายนอกหน่วยที่เลือก กว้าง/ยาว/สูง หน่วยเซนติเมตร น้ำหนักรวม KG เป็นตัวเลือก
4. กรอกขนาดพาเลท กว้าง/ยาว ความสูงตัวพาเลทเป็นตัวเลือก
5. Ti คือจำนวนต่อชั้น Hi คือจำนวนชั้น เป็นจำนวนเต็มบวก
6. ตรวจสรุปแล้วกด **บันทึกรุ่นพาเลท** แยกจากปุ่มบันทึกข้อมูลสินค้า

ตัวอย่าง 1 ลัง = 20 ถุง, Ti=10, Hi=5 จะเท่ากับ 50 ลัง = 1,000 ถุง/พาเลท
กรณี 6 ซอง/กล่อง และ 10 กล่อง/ลัง เลือก OUTER จะใช้ 60 ซอง/ลัง
ไม่แปลง ml หรือกรัมของเนื้อสินค้าเป็น Dimension ลัง
ภาพมุมบนและด้านข้างเป็นสัญลักษณ์จำนวน ไม่ใช่ผังเรียงจริงหรือผลตรวจความแข็งแรง

## กฎและสิทธิ์

- VIEW/EDIT ใช้สิทธิ์ข้อมูลสินค้ารายหมวดเดิม Admin ใช้ได้ทั้งหมด
- เก็บรุ่นเดิม ไม่แก้ทับ Dimension หรือ Ti/Hi ให้เพิ่มรุ่นด้วยวันเริ่มใช้ใหม่
- รหัสรูปแบบ + วันเริ่มใช้ซ้ำภายในสินค้าเดียวกันไม่ได้
- เลือกรุ่นเปิดใช้ล่าสุดที่ EffectiveFrom <= วันที่อ้างอิง แยกแต่ละรูปแบบ
- ปิดรุ่นล่าสุดแล้วรุ่นเก่าที่เปิดอยู่มีผลอีกครั้ง หากต้องการหยุดทั้งรูปแบบต้องปิดทุกรุ่นของรูปแบบนั้น
- เปิด/ปิดใช้ Revision ป้องกันผู้ใช้บันทึกทับสถานะที่ผู้อื่นเพิ่งแก้
- เก็บชื่อหน่วยและอัตราบรรจุจากรุ่นที่เลือกเป็น snapshot ในรุ่นพาเลท
- Ti 1–10000, Hi 1–1000, Dimension ทศนิยมไม่เกิน 3 ตำแหน่ง
- จำนวนหน่วยสต๊อกต่อพาเลทไม่เกิน 999999999999
- การเปลี่ยน Master ไม่เปลี่ยนยอดสต๊อกหรือจำกัดความจุโลเคชั่น

## API

- GET /api/products/:id/pallet-versions?date=YYYY-MM-DD : ประวัติ รุ่นที่มีผล รูปแบบบรรจุ และ canEdit
- POST /api/products/:id/pallet-versions : เพิ่มรุ่นใหม่
- PATCH /api/products/:id/pallet-versions/:versionId : isActive และ revision จาก RevisionToken

รอบนี้เป็น Master/API/UI เท่านั้น ยังไม่ผูก PalletVersionId หรือ snapshot กับใบรับ/ใบส่งจริง
